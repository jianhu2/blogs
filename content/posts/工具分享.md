# 开发者工具与社区资源清单

## 软件类

### uTools

[uTools](https://www.u-tools.cn/download/) 是一款插件化的桌面效率工具，免费版可以安装使用 10 个插件。

常用插件：

- 本地搜索：基于 Everything 的文件搜索及预览。
- 聚合翻译：聚合多种在线翻译。
- 小工具：JSON 格式化、C++ 函数速查、文本/代码比较等。
- 编码小助手：时间戳、Base64 编解码、哈希加密、进制转换等。
- 颜色助手：提取颜色。
- Chrome 小助手：Chrome 书签搜索。

下载地址：[https://www.u-tools.cn/download/](https://www.u-tools.cn/download/)

![](https://cdn.nlark.com/yuque/0/2025/png/26909551/1742867295148-5dd340e1-3e7f-4c8e-be37-d5855ef80550.png)

### v2rayN

[v2rayN](https://github.com/2dust/v2rayN/releases) 是一个基于 Xray / sing-box 的跨平台可视化代理客户端，用于管理和使用各种代理协议。

安装后需要导入配置或订阅，代理配置可以参考站内的[《代理客户端使用说明》](/posts/代理客户端使用说明/)。

下载地址：[https://github.com/2dust/v2rayN/releases](https://github.com/2dust/v2rayN/releases)

### PyCharm

[PyCharm](https://www.jetbrains.com/zh-cn/pycharm/download/?section=windows) 是 JetBrains 面向 Python 开发的 IDE。建议通过 JetBrains Toolbox App 或官方安装包安装，并使用 JetBrains Account 管理授权。

下载地址：[https://www.jetbrains.com/zh-cn/pycharm/download/?section=windows](https://www.jetbrains.com/zh-cn/pycharm/download/?section=windows)

jetbrains家族IDE激活码：[https://ckey.run/]

![image](/images/ckey.png)

### ApowerREC

[ApowerREC](https://www.apowersoft.cn/record-all-screen) 是一款录屏软件。建议使用官方版本，或按需求选择 OBS Studio、系统自带录屏等替代方案。

官网地址：[https://www.apowersoft.cn/record-all-screen](https://www.apowersoft.cn/record-all-screen)

历史地址：[https://github.com/cappuccino5/share-tools](https://github.com/cappuccino5/share-tools)

## 社区与刷题

### GitHub

[GitHub](https://github.com/) 是全球最大的代码托管与协作开发平台，建议注册账号并熟悉 Star、Fork、Issue、Pull Request 等基础功能。

地址：[https://github.com/](https://github.com/)

### LINUX DO

[LINUX DO](https://linux.do/) 是一个以 AI、编程和技术资源分享为核心的中文开发者社区。注册登录后可以使用站内搜索。

地址：[https://linux.do/](https://linux.do/)

### V2EX

[V2EX](https://www.v2ex.com/) 是程序员聚集、讨论技术与互联网话题的社区论坛。

地址：[https://www.v2ex.com/](https://www.v2ex.com/)

### NodeSeek

[NodeSeek](https://www.nodeseek.com/) 是面向主机、VPS、服务器、域名和建站运维方向的中文社区，适合关注 VPS 选型、IDC 信息、线路质量、服务器优惠和基础设施实践。

地址：[https://www.nodeseek.com/](https://www.nodeseek.com/)

### LeetCode + 牛客

- LeetCode：[https://leetcode.cn/](https://leetcode.cn/)
- 牛客：[https://www.nowcoder.com/](https://www.nowcoder.com/)
