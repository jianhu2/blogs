# 家宽 LXC 穿透方案成本评估

> **版本**:v1.0
> **日期**:2026-05-13
> **范围**:仅评估 gost + LXC + VPS 家宽穿透方案的投入成本,不重复讨论技术可行性。

---

## 一、评估口径

本评估按个人或小团队自托管场景估算,默认技术方案为:家宽宿主机运行 LXC 容器,gost 负责反向隧道,VPS 作为公网中转入口。

价格采用 2026 年 5 月常见采购区间估算,不同地区、促销活动、存量硬件和 VPS 供应商会显著影响实际支出。若已有可用宿主机、SSD 或 VPS,对应成本可按 0 计入。

---

## 二、一次性成本

| 项目 | 规格 | 估算成本(人民币) |
|------|------|----------------|
| 树莓派主机 | Raspberry Pi 4B 4GB / Pi 5 | 500-800 |
| 存储 | 256GB SATA SSD + 转接 | 150-250 |
| 电源、散热、外壳 | 标准套件 | 100-150 |
| 网线、配件 | - | 50 |
| **小计** | | **800-1250** |

如果已有闲置树莓派、N100 小主机、二手 ThinkCentre 或同等性能设备,一次性硬件成本可降至 **0-300 元**。但仍建议使用 SSD 承载系统和容器 rootfs,避免 SD 卡长期写入导致稳定性问题。

---

## 三、持续性成本

| 项目 | 规格 | 估算成本(人民币/月) |
|------|------|------------------|
| VPS(中转节点) | 1C/512MB/100Mbps,境外 | 15-40 |
| VPS 流量 | 按 500GB/月估算 | 含在套餐内或 5-20 |
| 域名(可选,DDNS 也行) | .com / .xyz 摊销 | 5-10 |
| 家宽电费(低功耗主机 24x7) | 约 5W x 720h | 2-3 |
| **小计** | | **22-73** |

全年持续成本约 **260-880 元**。如果使用 Oracle Cloud 免费 ARM 实例、学生优惠云主机或已有闲置 VPS,VPS 部分可以进一步降低。

---

## 四、隐性成本

人力维护成本是最容易被低估的部分。初次搭建预计 **4-8 工时**,包括 LXC 学习、gost 调试、防火墙配置、密钥分发和基础监控配置。

稳定运行后,日常维护约 **1-2 小时/月**,主要用于版本升级、证书续期、日志巡检、备份检查和故障演练。异常排障峰值约 **2-4 小时/次**,常见触发点包括 VPS 网络异常、家宽重拨、证书过期、容器网络变化和 gost 配置变更。

---

## 五、与其他方案成本对比

| 方案 | 月成本 | 容器数上限 | 备注 |
|------|-------|----------|------|
| 本方案(gost + LXC + VPS) | 22-73 元 | 受限于宿主机内存,实测 10-20 个轻量容器 | 完全自主 |
| 阿里云轻量服务器 2C2G | 60-100 元 | 5-10 个 Docker | 国内访问快,但公开网站通常有备案要求 |
| 腾讯云轻量同档 | 60-90 元 | 5-10 个 Docker | 与阿里云轻量类似 |
| AWS Lightsail 2GB | 80-120 元 | 5-10 个轻量服务 | 海外节点,链路取决于地区 |
| frp + 免费云服务 | 0-30 元 | 不限 | 稳定性依赖免费服务方 |
| Cloudflare Tunnel | 0 元 | 不限(限 HTTP/S) | 仅适合 Web 服务,流量经过 Cloudflare |

本方案在"持续成本 + 多容器容量"维度上具备优势,尤其在容器数达到 5 个以上时,单位服务成本通常低于直接购买多台云主机。

---

## 六、成本结论

如果已经有可用宿主机,本方案主要成本是 VPS 和域名,月度支出可控制在 **20-70 元**区间。如果需要新购硬件,首年总成本会明显抬高,但从第二年开始主要只剩持续性成本。

从成本角度看,本方案适合长期运行、多容器、多协议、自主可控的自托管场景。不适合只临时暴露一个 Web 服务、完全不想维护基础设施,或对故障排障时间高度敏感的场景。
