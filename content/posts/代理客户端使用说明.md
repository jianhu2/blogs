# 1.代理客户端安装


+ 不同环境下的安装方式



## 1.1 windows电脑安装


```shell
https://github.com/kelleygo/shadowsocks/releases/download/1.3.2/shadowsocks-windows-amd64.zip
```



## 1.2 android-app安装


```shell
// shadowsocks
https://github.com/kelleygo/shadowsocks/releases/download/1.3.2/shadowsocks.android-app.apk
      
// v2ray-plugin
https://github.com/kelleygo/shadowsocks/releases/download/1.3.2/v2ray-x86-1.3.3.apk
```



+ 如果安装v2ray-plugin插件报错`该应用与此设备的 CPU 不兼容`，尝试安装1.3.2版本



```shell
https://github.com/kelleygo/shadowsocks/releases/download/1.3.2/shadowsocks.plugin.v2ray-android.1.3.2.apk
```



+ 如果安装v2ray-plugin插件报错还报错，到github找不同的版本安装



```shell
https://github.com/shadowsocks/v2ray-plugin-android/releases
```

# 2. 配置


## 2.1 Windows配置游览器代理


1. 安装Chrome浏览器, 如已经安装请跳过
2. Chrome浏览器地址栏输入chrome://extensions/, 开启开发者模式.
3. 拖动SwitchyOmega-xxx.crx至chrome://extensions/页面  
   如出现 CRX_HEADER_INVALID 错误，则拖动 SwitchyOmega-xxx.zip 文件安装
4. 点击Chrome浏览器左上角SwitchyOmega图标, 再点击选项
5. 点击"导入/导出", 点击"从文件恢复", 选择"OmegaOptions-20180124.bak"文件
6. 点击Chrome浏览器左上角SwitchyOmega图标, 切换为"AutoSwitch/自动代理"
7. 部分不能自动代理的网站可以选择Shadowsocks模式
8. 开启shadowsocks, 自由上网
9. 如提示安装.NetFramework工具, 请核对版本后安装 NDP462-KB3151800-x86-x64-AllOS-ENU.exe ,  
   当前版本为.Net V4.6.2

## 2.2 配置Git


开启http代理模式：



```shell
git config --global http.proxy http://127.0.0.1:1080
```



关闭http代理模式



```shell
git config --global --unset http.proxy
```



注意: http.proxy选项仅对https://....链接代理, 不代理git://相关的连接



注意: 如需对其他软件进行代理, 请另行搜索



# 3.高级应用


+ Shadowsocks默认配置连接至p.domain.com服务器开启代理服务
+ Shadowsocks默认端口号为1080
+ Shadowsocks"启用全局代理"选项开启后将代理整个本地网络
+ SwitchyOmega可以通过本地代理端口1080(SOCKSV5)访问墙外网站
+ SwitchyOmega自动代理模式可以智能区分墙内墙外开启代理
